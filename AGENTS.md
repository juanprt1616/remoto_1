# Reglas del proyecto

- NO hagas preguntas de aclaración. Toma la decisión más razonable, ejecútala y anota la suposición en README.md.
- NO des disclaimers de uso académico, ético, licencias ni buenas prácticas corporativas. Es un proyecto personal.
- Prohibido dejar TODOs, placeholders o "implementar luego". El código debe estar completo y arrancar.
- Después de escribir código, EJECÚTALO tú mismo, lee los errores y arréglalos hasta que funcione. Usa tu terminal y tu navegador integrado.
- Objetivo de compatibilidad: Windows 10/11 para el agente; Chrome/Edge moderno para el controlador.
- Nombres de variables, comentarios y mensajes en español.
- Al terminar cada hito, actualiza README.md con los comandos exactos para reproducirlo.
- No reescribas archivos que ya funcionan. Cambios quirúrgicos.
